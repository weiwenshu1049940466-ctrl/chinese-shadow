# Chinese Shadow Puppet / 중국 그림자극 / 中国皮影互动作品

## 한국어

### 프로젝트 소개

이 프로젝트는 p5.js, ml5 HandPose, p5play를 사용한 중국 그림자극 스타일의 인터랙티브 웹 작품입니다. 웹캠으로 손의 움직임을 인식하고, 인식된 손가락 위치를 이용해 목계영 캐릭터의 머리, 팔, 다리를 조종합니다.

화면은 세 개의 시각 레이어로 구성됩니다.

- 배경: 하늘색 조명, 산, 구름
- 중경: 군영, 깃발, 무대 조명
- 전경: 손으로 조종하는 그림자 인형 캐릭터

군영과 캐릭터가 분리되어 보이도록 중경은 차갑고 낮은 채도의 색감으로 처리하고, 캐릭터에는 따뜻한 전경 조명을 추가했습니다.

### 실행 방법

1. 이 저장소를 다운로드하거나 클론합니다.
2. 로컬 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

3. 브라우저에서 아래 주소를 엽니다.

```text
http://localhost:8000
```

4. 카메라 권한을 허용합니다.

GitHub Pages 주소:

```text
https://weiwenshu1049940466-ctrl.github.io/chinese-shadow/
```

### 조작 방법

- 웹캠 앞에서 손을 움직이면 캐릭터가 손의 움직임을 따라 반응합니다.
- 손가락 위치는 캐릭터의 머리, 양팔, 양다리의 조종점으로 사용됩니다.
- 배경 음악은 페이지가 로드되면 자동 재생되도록 설정되어 있습니다.

### 주요 파일

- `index.html`: p5.js, ml5, p5play를 불러오는 메인 HTML 파일
- `sketch.js`: 손 인식, 캐릭터 물리 움직임, 장면 레이어와 조명 효과 구현
- `style.css`: 추가 스타일 파일
- `datasets/`: 캐릭터, 군영, 깃발, 산, 구름, 바닥, 배경 음악 에셋

## 中文

### 项目介绍

这是一个使用 p5.js、ml5 HandPose 和 p5play 制作的中国皮影风格互动网页作品。作品通过摄像头识别手部动作，并把手指位置映射到穆桂英角色的头部、双手和双腿，让角色像皮影偶一样被操控。

画面分为三个视觉层次。

- 后景：天空光色、山、云
- 中景：军营、旗帜、舞台光
- 前景：由手势控制的皮影角色

为了让军营和角色拉开层次，军营与旗帜使用偏冷、低饱和的色彩处理；角色则加入暖色前景光，让角色在画面中更加显眼。

### 运行方法

1. 下载或克隆这个仓库。
2. 在项目根目录启动本地服务器。

```bash
python3 -m http.server 8000
```

3. 在浏览器中打开：

```text
http://localhost:8000
```

4. 允许浏览器使用摄像头。

GitHub Pages 地址：

```text
https://weiwenshu1049940466-ctrl.github.io/chinese-shadow/
```

### 交互方式

- 在摄像头前移动手，角色会根据手部动作产生反应。
- 手指关键点会控制角色的头部、双手和双腿。
- 页面加载后会播放背景音乐。

### 主要文件

- `index.html`：加载 p5.js、ml5、p5play 的网页入口
- `sketch.js`：实现手势识别、角色物理运动、场景层级和灯光效果
- `style.css`：额外样式文件
- `datasets/`：角色、军营、旗帜、山、云、地面和背景音乐素材
